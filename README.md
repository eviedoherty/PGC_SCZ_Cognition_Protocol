This repository contains code for deriving the general cognitive factor i.e. 'g', and the genetic analysis protocol
for the PGC SCZ Working Group Cognition Subgroup project "Exploring the Genetic Underpinnings of Cognition in Schizophrenia Case-only Samples: 
A Meta-Analytic Approach"

A test dataset has been included here to provide an example of the expected data structure and for demonstrating code application (PGC_Cognition_Dummy_Dataset.csv)
